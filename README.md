# scoop-hivemend

[Scoop](https://scoop.sh) bucket for [Hivemend](https://github.com/Tuigse-oss/HiveMend), the free, open-source registry cleaner for Windows 10 and 11.

```powershell
scoop bucket add hivemend https://github.com/Tuigse-oss/scoop-hivemend
scoop install hivemend
```

Update with `scoop update hivemend`. The manifest is updated automatically when a Hivemend release is published; please report problems in the [Hivemend issues](https://github.com/Tuigse-oss/HiveMend/issues).
